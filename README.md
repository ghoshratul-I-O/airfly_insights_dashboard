# ✈️ AirFly Insights Dashboard

## 📌 Project Description
AirFly Insights Dashboard is an interactive airline data analysis dashboard built using Python and Streamlit.  
The project focuses on analyzing airline operations data such as delays, cancellations, airport congestion, and flight trends through interactive visualizations.

This project demonstrates data cleaning, data analysis, and dashboard development skills using real-world airline data.

| Tool | Purpose |
|------|---------|
| Python | Data Processing |
| Pandas | Data Cleaning & Analysis |
| Matplotlib / Seaborn | Data Visualization |
| Streamlit | Dashboard Application |

## 💻 How to Run This Project (Step-by-Step)

Follow these steps if you want to run this project on your system.

### Step 1 — Clone the Repository
```
git clone https://github.com/your-username/airfly_insights_dashboard.git
```

### Step 2 — Go to Project Folder
```
cd airfly_insights_dashboard
```

### Step 3 — Create Virtual Environment (Recommended)
```
python -m venv venv
```

Activate virtual environment:

**Windows:**
```
venv\Scripts\activate
```

**Mac/Linux:**
```
source venv/bin/activate
```

### Step 4 — Install Required Libraries
```
pip install -r requirements.txt
```

### Step 5 — Run the Streamlit Dashboard
```
streamlit run app.py
```

After running the above command, the dashboard will open automatically in your browser.

If it does not open, go to:
```
http://localhost:8501
```

## 📊 Dataset
The dataset used in this project contains airline flight information such as:

- Flight Date  
- Airline  
- Origin Airport  
- Destination Airport  
- Departure Delay  
- Arrival Delay  
- Cancellation Status  
- Cancellation Reason  
- Flight Distance  
- Scheduled Time  

**Dataset Link:**  
https://www.kaggle.com/datasets/mahoora00135/flights
